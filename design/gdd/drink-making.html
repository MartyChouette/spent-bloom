Overview

Drink Making is a physical pouring minigame that runs during date Phase 2. The player picks up a bottle, tilts it over a glass using a drag gesture, and pours ingredients in layers to build a drink. A cutaway UI panel shows the glass filling in real time. The finished drink is scored across five dimensions — ingredient order, layer accuracy, fill level, garnish, and overflow penalty — and the total score influences the date outcome.

Ingredients have physical properties (weight, fizziness, viscosity) that govern how foam builds and how layers sort. The glass glows during pouring to signal active state.

Active system: DrinkPourManager Active    SimpleDrinkManager Legacy — do not reference

Player Fantasy

The player should feel like a careful, unhurried bartender in their own kitchen. Tilting a bottle should feel weighty and deliberate. Watching layers settle in the cutaway view should feel satisfying — a well-made drink is visually legible as a column of distinct strata. Overflow should feel like a mistake that could have been avoided, not an arbitrary punishment. A perfectly poured drink should leave the player with a quiet sense of craft.

Pour Drag Input

rate = (dragDistance / 200px)² tiltAngle = rate × 90° liquidPerSec = ingredient.pourRate × rate × glass.fillRateMultiplier
  • dragDistance: pixel distance dragged from initial click point.
  • rate: ranges 0.0 (no drag) to 1.0 (200px or more). Clamped at 1.0.
  • The quadratic curve means small drags produce very little flow — the player must commit to pour meaningfully.
  • At 100px drag: rate = (100/200)² = 0.25, tiltAngle = 22.5°

Foam Mechanics

foamDelta = pourRate × foamMultiplier × (1 + fizziness) settleRate = weightedAverage(foamSettleRate, weighted by volume fraction) foam = max(0, foam - settleRate × deltaTime)
  • Foam accumulates on top of the liquid column during pours.
  • Between pours, foam settles using a weighted average of all poured ingredients' settle rates.
  • Rush penalty: pouring fizzy ingredients (fizziness > 0) at high rate causes extra foam. Decays when player slows or stops.
  • If foam alone pushes total above 1.0, the overflow flag triggers.

Pour Rate Formula

dragRate = (dragDistance / 200)² // [0, 1] tiltAngle = dragRate × 90 // degrees liquidPerSec = ingredient.pourRate × dragRate × glass.fillRateMultiplier

Foam Generation & Settling

// Generation (while pouring) foamDelta = liquidPerSec × ingredient.foamRateMultiplier × (1 + ingredient.fizziness) foam += foamDelta × deltaTime // Settling (while not pouring) settleRate = sum(ingredient.foamSettleRate × volumeFraction_i for each i) foam = max(0, foam - settleRate × deltaTime)

Layer Score

accuracy_i = clamp(1.0 - abs(actual_i - expected_i) / 0.08, 0, 1) layerScore = (sum(accuracy_i) / n) × 50 // Example (2 ingredients, both within tolerance): // actual = [0.40, 0.35], expected = [0.40, 0.35], tolerance = 0.08 // accuracy_0 = 1.0 - 0/0.08 = 1.0 // accuracy_1 = 1.0 - 0/0.08 = 1.0 // layerScore = (1.0 + 1.0) / 2 × 50 = 50

Fill Score

fillError = abs(actualFillLevel - 0.75) if fillError <= 0.10: accuracy = 1.0 - (fillError / 0.10) else: accuracy = 0.0 fillScore = accuracy × 30 // Example (fill level = 0.82): // fillError = |0.82 - 0.75| = 0.07 // accuracy = 1.0 - (0.07 / 0.10) = 0.30 // fillScore = 0.30 × 30 = 9

Order Score

if (pouringSequence == recipeSequence): orderScore = 10 elif (sequenceIsOneOutOfOrder): // exactly one adjacent pair swapped orderScore = 5 else: orderScore = 0

Acceptance Criteria

  • ✓Drag-to-rate quadratic: 100px → rate = 0.25. 200px → rate = 1.0. 300px → rate clamped at 1.0.
  • ✓Tilt angle: rate 0.25 → tiltAngle = 22.5°. rate 1.0 → tiltAngle = 90°.
  • ✓Order score — correct sequence: Pour in recipe order. Verify orderScore = 10.
  • ✓Order score — one out of order: Reverse two adjacent. Verify orderScore = 5.
  • ✓Order score — multiple out of order: Differ by two positions. Verify orderScore = 0.
  • ✓Layer score — within tolerance: Pour to exactly expected portion. Verify accuracy = 1.0.
  • ✓Layer score — beyond tolerance: 0.09 beyond expected (outside 0.08). Verify accuracy = 0.0.
  • ✓Fill score — at ideal: Pour to exactly 0.75. Verify fillScore = 30.
  • ✓Fill score — at tolerance edge: Pour to 0.85 (0.10 above ideal). Verify fillScore = 0.
  • ✓Overflow penalty: Fill past 1.0 (liquid + foam). Verify −15 applied and overflow flag set.
  • ✓Garnish cap: Apply 3 correct garnishes (15 pts potential). Verify garnish score capped at 10.
  • ✓Like override: Neutral-preference recipe, score exactly 80. Verify outcome = Like.
  • ✓Dislike overrides score: Disliked recipe, score 95. Verify outcome = Dislike (not Like).
  • ✓Liked recipe at 59: Liked recipe, score 59. Verify outcome is not Like.
  • ✓State machine full pass: Idle → ChoosingGlass → Pouring → Score → Idle. Verify DateSessionManager receives score.
  • ✓Foam settling: Pour fizzy ingredient, stop. Verify foam volume decreases at rate consistent with foamSettleRate.
  • ✓Layer sorting by weight: Pour light then heavy. Verify cutaway shows heavy below light after settling.
