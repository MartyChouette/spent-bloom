Overview

The PSX rendering system gives Spent Bloom its signature lo-fi aesthetic by applying three cooperative layers of retro distortion. The system is globally togglable for accessibility and performance.

LayerComponentEffects
1 — Object ShaderPSXLit (Iris/PSXLit)Vertex snapping, affine UV warping, shadow dithering per-geometry
2 — Post-ProcessPSXPostProcessFeatureResolution downscale, color depth reduction, ordered dithering, tilt-shift blur
3 — Per-Object OverridePSXObjectSettingsMaterialPropertyBlock overrides per-renderer; no material instances created

Design rule: Artist materials are never swapped to PSXLit by code. The shader is assigned at scene build time and stays as authored. This prevents runtime material leaks, unexpected shader compilation stalls, and uncontrolled visual changes. Forbidden Pattern

Player Fantasy

The player should feel like they are playing a game remembered imperfectly — soft edges where sharpness should be, colors that pool rather than grade, a room that feels handmade rather than rendered.

The PSX look is not nostalgia for its own sake: it flattens emotional distance, making the apartment feel warmer and more intimate than a clean render would. The aesthetic should recede into atmosphere, noticed only when absent.

Runtime Toggle

The F4 key toggles PSXEnabled at runtime for A/B visual comparison during development. Available in editor play mode and development builds only.

Release Guard Required The F4 hotkey must be wrapped in #if UNITY_EDITOR or Debug.isDebugBuild. It must not ship in release builds.

Layer 1: Object Shader (PSXLit)

Applied to geometry that should participate in the retro aesthetic. Operates in three modes per-vertex.

Vertex Snapping

Vertex positions in clip space are quantized to a lower-resolution grid before rasterization. Produces the characteristic swimming geometry of early 3D hardware. Grid resolution set by _snapResolution. Global default equivalent to a 160×120 virtual framebuffer.

Affine Texture Mapping

Standard UV interpolation is perspective-correct (divides by W). Affine mapping skips the W division, producing warped, sliding textures of PSX-era polygons. _affineIntensity blends between perspective-correct (0) and fully affine (1). Global default: 1.0 (fully affine).

Shadow Dithering

Shadow boundaries use Bayer pattern stippling rather than smooth gradients. _shadowDither controls intensity. At 0, shadows are unaffected. At 1, full Bayer pattern applied to shadow penumbra.

Layer 2: Post-Process (PSXPostProcessFeature)

A URP Renderer Feature that runs a fullscreen blit each frame using the PSXPost shader. Applies four effects in sequence.

1. Resolution Downscale

Screen downscaled by resolutionDivisor (default 3.0) using point filtering, then upscaled back to native with point filtering. Produces large square pixels. At 3.0 on 1920×1080: renders at 640×360.

2. Color Depth Reduction (Posterization)

Each color channel quantized to colorDepth levels (default 32). Values are rounded, not interpolated. Matches the limited palette of early hardware.

3. Ordered Dithering

A Bayer matrix tiled across the screen thresholds dark regions. Two Bayer patterns selected by luminance:

Luminance ZonePatternThreshold
Bright (above shadow)None — no dither> 0.5
Mid-shadow (fine dither)Bayer4x4 (default)0.15 – 0.5
Deep shadow (coarse dither)Bayer2x2 (default)< 0.15

Dither intensity is also scaled by camera zoom (see Formulas).

4. Tilt-Shift Blur

A focal band defined by tiltShiftCenter (0–1 screen height, default 0.5) and tiltShiftWidth (default 0.15). Pixels outside the band blurred by tiltShiftRadius (default 8px). tiltShiftAmount (default 0) scales the overall effect — at 0, no blur applied.

Implementation Constraint

Always call SetPropertyBlock before reading back values. Never call GetPropertyBlock on a fresh MPB — it returns default values, not material values. PSXObjectSettings initializes a fresh MPB in Awake and writes to it immediately.

Screen Resolution After Downscale

renderWidth = floor(nativeWidth / resolutionDivisor)
renderHeight = floor(nativeHeight / resolutionDivisor)

// Example: 1920×1080, divisor=3.0 → 640×360
// Fractional: 1920×1080, divisor=2.5 → 768×432

Posterization Per Channel

quantized = floor(channel × colorDepth) / colorDepth

// channel ∈ [0, 1], colorDepth = 32 default
// Example: channel=0.73, depth=32
// → floor(0.73×32)/32 = floor(23.36)/32 = 23/32 = 0.71875

Dither Zoom Scaling

ditherZoom = cameraOrthographicSize / ditherZoomReference
scaledDitherIntensity = ditherIntensity × ditherZoom

// ditherZoomReference = 5.0 (authored camera size)
// cameraSize=5.0: scaledDither = ditherIntensity × 1.0 (as authored)
// cameraSize=2.5: scaledDither = ditherIntensity × 0.5 (finer, tiles denser)
// cameraSize=10.0: scaledDither = ditherIntensity × 2.0 (coarser at wide zoom)

Bayer Luminance Threshold Decision

luminance = dot(color.rgb, float3(0.299, 0.587, 0.114))

if luminance > shadowThreshold (0.5): pattern = none
elif luminance > deepShadowThreshold (0.15): pattern = finePattern (Bayer4x4)
else: pattern = coarsePattern (Bayer2x2)

Tilt-Shift Blur Falloff

distanceFromFocal = abs(screenUV.y − tiltShiftCenter) − (tiltShiftWidth / 2)
blurWeight = saturate(distanceFromFocal / tiltShiftRadius) × tiltShiftAmount

// blurWeight = 0 inside focal band
// ramps to tiltShiftAmount outside focal band

Edge Cases

resolutionDivisor below 1.0

Renders at higher than native resolution — wasteful, no PSX effect. The system should clamp the minimum to 1.0. Fractional values between 1.0 and 2.0 are valid for subtle pixelation.

colorDepth = 256

Maximum fidelity — posterization is imperceptible. Valid as a "PSX light" mode for accessibility without full disabling.

colorDepth = 4

Extreme banding, intentional for artistic emphasis on specific scenes. No system error, but QA should verify the palette looks authored rather than broken.

PSXObjectSettings on a SkinnedMeshRenderer

The MPB must be set on SkinnedMeshRenderer, not MeshRenderer. The component type must be checked in Awake when fetching the renderer reference.

Object with PSXObjectSettings and no renderer

Awake should log a warning and disable the component. No null reference propagation.

ReduceMotion enabled mid-session

PSXObjectSettings reads AccessibilitySettings.ReduceMotion and updates vertex snap and affine parameters within one frame via OnSettingsChanged callback. No restart required.

Camera size = 0 in dither zoom formula

ditherZoom would be 0, making dither invisible. Guard with max(cameraSize, 0.01) to prevent divide-by-zero if ditherZoomReference were ever 0.

PSXEnabled toggled during ScreenFade

The ScreenFade panel remains white (by design — see technical preferences). Toggling PSXEnabled during a fade transition does not affect the fade panel or its color.

PSXLit materials on UI Canvas objects

Canvas objects render outside the standard URP camera pass. PSXPostProcessFeature does not process UI canvas overlays. This is expected behavior — UI intentionally bypasses the retro effect.

F4 hotkey in release build

The F4 runtime toggle must be disabled in release builds. A #if UNITY_EDITOR or Debug.isDebugBuild guard is required. Shipping the toggle would expose an unintended accessibility shortcut.

Acceptance Criteria

  • ✓Resolution downscale: at resolutionDivisor=3.0 on 1920×1080, effective render is 640×360. Pixel edges visible as squares at native display size.
  • ✓Posterization: at colorDepth=4, color output shows no more than 4 distinct values per channel. Screenshot comparison confirms visible banding.
  • ✓Dither in shadows: pixels at luminance < 0.15 show Bayer2x2. Pixels at 0.15–0.5 show Bayer4x4. Pixels above 0.5 are undithered.
  • ✓Dither zoom scaling: at cameraSize=5.0, dither as designed. At cameraSize=10.0, tiles coarser (2.0×). At cameraSize=2.5, tiles finer (0.5×).
  • ✓Vertex snapping: moving object with PSXLit visibly snaps to grid. At _snapResolution=0, same object moves smoothly.
  • ✓Affine UV warping: large polygon with grid texture at affineIntensity=1.0 shows UV warping at corners. At 0.0, perspective-correct.
  • ✓Per-object override does not create material instances: 10 PSXObjectSettings components after 60 seconds confirm Material count has not increased from baseline.
  • ✓PSXEnabled=false disables post-process: scene renders without downscale, posterization, or dithering. Object shader properties remain.
  • ✓ReduceMotion suppresses vertex snap and affine: PSXLit object moves smoothly, UV perspective-correct. Shadow dithering remains.
  • ✓F4 toggle: in editor play mode, pressing F4 toggles post-process off and on within one frame. Visual difference immediately apparent.
  • ✓ReduceMotion live update: enable ReduceMotion while in play mode. Vertex snap stops within one rendered frame, no restart required.
  • ✓Tilt-shift at amount=1.0: pixels outside the focal band are blurred. Pixels inside are unblurred. Blur radius matches tiltShiftRadius in screen pixels.
